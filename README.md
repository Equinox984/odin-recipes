# Odin Recipes

A simple recipe website built as part of [The Odin Project](https://www.theodinproject.com/) Foundations course.

## About

This project practices core HTML skills: document structure, lists, images, and relative links. It consists of a home page that links to three individual recipe pages.

## Built With

- HTML5

## Viewing

Open `index.html` in your browser, or serve the project locally:

```bash
python3 -m http.server 8000
```

## Project Structure

```
odin-recipes/
├── index.html
├── styles.css
└── recipes/
    ├── chicken.html
    ├── bulgogi.html
    └── noodles.html
```
